# Password Generator 🔐

Pythonで作成したパスワードジェネレーターです。  
英字・数字・記号を自由に組み合わせ、安全性の高いランダムなパスワードを自動生成します。

## 🧩 機能
- 英字（大文字・小文字）、数字、記号の組み合わせ設定
- 指定した文字数のパスワードを自動生成
- シンプルで読みやすいコード構成
- 使いやすいインターフェース（今後GUI対応予定）

## 💻 使用技術
- **Python 3**
- ライブラリ：`random`, `string`, `tkinter`（予定）

## 🚀 使い方
1. `password_generator.py` を実行します  
2. 文字数を指定すると自動的にパスワードが生成されます

```
python3 password_generator.py
```
